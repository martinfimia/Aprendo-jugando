# Aprendo jugando

Primer prototipo web para practicar vocabulario mediante tarjetas interactivas.

## Funciones actuales
- Tarjetas reversibles con palabra y traducción.
- Pronunciación mediante la voz del navegador.
- Selector de idioma para palabras y traducciones.
- Crear una lista pegando parejas con el formato `palabra; traducción`.
- Mezclar tarjetas y navegar entre ellas.
- Guardado local en el navegador.
- Selección y vista previa de una imagen; los PDF se pueden seleccionar, pero aún no se extrae su texto.

## Publicar con GitHub Pages
1. Abre **Settings** en este repositorio.
2. En el menú lateral, entra en **Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
5. Espera a que GitHub termine la publicación.

La dirección esperada será https://martinfimia.github.io/Aprendo-jugando/

## Limitaciones de esta primera versión
La foto/PDF no se procesa automáticamente ni se envía a ningún servicio de IA. Las tarjetas se guardan solo en el navegador de ese dispositivo. No hay todavía cuentas familiares, sincronización entre dispositivos ni generación automática de juegos con IA.
